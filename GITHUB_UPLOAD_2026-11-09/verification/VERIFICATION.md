# Reproduction test (9 November 2026)

A clean folder containing only `scripts/` was used. The pipeline was run with
`Rscript -e 'source("scripts/00_run_complete_pipeline.R")'` on macOS, R 4.6.0
(see `sessionInfo_run_2026-11-09.txt`). Total run time was about 65 seconds, plus the
download of the GEO files.

| Check | Result |
|---|---|
| Fresh GEO series matrix and GPL10558 annotation vs the files used for the dissertation (MD5) | identical |
| `pheno3_matched.rds` rebuilt from GEO vs the dissertation object | `identical()` = TRUE |
| `expr2_probe_matrix.rds` rebuilt from GEO vs the dissertation object | `identical()` = TRUE |
| 16 result and table CSV files vs the dissertation outputs (tolerance 1e-8) | all identical |
| 9 leading-edge CSV files vs the earlier manuscript analysis | byte-identical |
| `19_verify_headline_results.R` (headline numbers in the manuscript) | all checks passed |

Defects found and fixed while testing (scripts 01-17 otherwise unchanged):
1. Nothing created the `results_v2/` folder before script 02 wrote to it. The master script now creates all output folders.
2. Script 09 called `install.packages()` unconditionally. Replaced with an availability check.
3. The phenotype object was originally built by hand in Excel from the GEO metadata. Script `00a_prepare_inputs_from_GEO.R` now builds it directly from the GEO file and reproduces the original object exactly.

## Addendum, 9 November 2026: median follow-up (script 20)

`20_median_followup.R` was added after the verification above. A full run from a clean copy completed with exit status 0 and `19_verify_headline_results.R` passed all checks, including the two new follow-up checks (270 patients: 1003 days; 250 Cox patients: 1002 days). That run used the GEO files from the earlier verified download, confirmed by the script's MD5 checks, because NCBI would not complete a download at the time of the test. `00a_prepare_inputs_from_GEO.R` was also changed so that an empty or interrupted download is discarded and reported instead of being read as a cached file; that download path was not re-run after the change.

## Addendum, 9 November 2026: treatment sensitivity analysis (script 21)

`21_treatment_sensitivity.R` implements the plan in `treatment_sensitivity_plan_2026-11-09.md` (written before any model was fitted). Inside the script, the same functions run without the treatment term must reproduce the main limma, fgsea, score and Cox results (control: passed). A full run from a clean copy then passed `19_verify_headline_results.R`, including five regression checks on the sensitivity numbers (these checks were added after the run). As in the previous addendum, that run used the earlier verified local GEO files. The gene-level limma tables for the sensitivity models are regenerated by the run and are not stored in `reference_outputs/`.
