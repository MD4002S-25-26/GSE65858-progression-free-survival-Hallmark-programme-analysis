# GSE65858 progression-free survival: Hallmark programme analysis

Analysis code for the manuscript *Programme-level transcriptomic associations with progression-free
survival in head and neck squamous cell carcinoma: a secondary analysis of GSE65858*
(citation and DOI: see `CITATION.cff`; to be added at the first release).

The analysis uses only public data (NCBI GEO series GSE65858, platform GPL10558). No new
participant data were collected. This repository is research code, not clinical software.

## Quick start

```bash
git clone https://github.com/MD4002S-25-26/GSE65858-progression-free-survival-Hallmark-programme-analysis
cd GSE65858-progression-free-survival-Hallmark-programme-analysis
Rscript install_requirements.R                                  # once, installs missing packages
Rscript -e 'source("scripts/00_run_complete_pipeline.R")'       # full analysis, about 1-2 minutes
```

The first run downloads about 90 MB from GEO (needs internet and about 300 MB of disk). The
last step (`19_verify_headline_results.R`) stops with an error if the headline numbers in the
manuscript are not reproduced.

## Scripts

| Script | Purpose |
|---|---|
| `00_run_complete_pipeline.R` | Runs everything below in order and creates the output folders |
| `00a_prepare_inputs_from_GEO.R` | Downloads GEO files; builds `pheno3_matched.rds` and `expr2_probe_matrix.rds` |
| `01` to `04` | Phenotype and two-year PFS groups; probe-to-gene collapse (22,001 genes); limma unadjusted and adjusted |
| `05_fgsea_hallmark.R` | Ranked Hallmark enrichment (`set.seed(123)` before `fgseaMultilevel`) |
| `06`, `07` | Sample-level Hallmark scores; Cox models and proportional-hazards tests |
| `08_pipeline_audit.R` | Consistency checks |
| `09` to `13` | Table 1, Table 2, Figures (volcano, enrichment, sample-level scores) |
| `14` to `17`, `supplementary_table_helpers.R` | Supplementary tables for enrichment, scores and Cox models |
| `18_leading_edge_overlap.R` | Leading-edge overlap analysis added for the manuscript (deterministic) |
| `19_verify_headline_results.R` | Confirms the headline numbers reported in the manuscript |

gene-level expression matrix is regenerated by the pipeline and is not stored.

## Verification

See `verification/VERIFICATION.md`. A clean-folder run reproduced the dissertation input objects
exactly and all result tables to within 1e-8.

## Changes relative to the dissertation version of this repository

- Added `00a_prepare_inputs_from_GEO.R`. The phenotype file was originally built by hand in Excel;
  it is now built from the GEO file and matches the original object exactly.
- Replaced the master script: it now creates the output folders, runs `00a`, `18` and `19`.
- Script 09: an unconditional `install.packages()` call was replaced by an availability check.
- Added scripts 18 and 19, `install_requirements.R`, `CITATION.cff` and this README.
- `pheno3_matched.rds` and `expr2_probe_matrix.rds` no longer need to be stored; they are rebuilt.
